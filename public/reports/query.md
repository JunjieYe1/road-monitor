## 接口概述


包含 3 个接口：

- `POST /query/select`
- `POST /query/selectgroup`
- `POST /query/solve`

## 通用约定

| 项目 | 内容 |
| --- | --- |
| 鉴权 | `Authorization: Bearer <token>` |
| 请求头 | `Content-Type: application/json` |
| 返回类型 | `application/json` |


## 返回字段总览

| 数据来源 | 实际返回字段 |
| --- | --- |
| `检测病害信息汇总表` | `序号`、`年份`、`区域`、`公司`、`标项`、`来源文件`、`编号`、`道路名称`、`病害类型`、`风险等级`、`检测日期`、`平面尺寸`、`病害体底深`、`病害体顶深`、`纬度`、`经度`、`具体位置`、`道路现状`、`病害体与周边管线相对位置`、`初步成因分析`、`塌陷发生可能性`、`处置建议`、`编制人`、`审核人`、`雷达图像`、`电子地图`、`现场照片`、`验证照片`、`隐患周边地下管网图`、`对应病害群组编号`、`群组内序号`、`检测项目归属行政区划` |

## 1. `/query/select`

### 用途

查询 `检测病害信息汇总表`，支持按年份、区域、道路名称、病害类型筛选病害明细。

### 请求信息

| 项目 | 内容 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/query/select` |

### 请求体

四个筛选项都可空；全部为空时返回全表数据。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `years` | `string \| string[]` | 否 | 年份筛选，支持多选 |
| `regions` | `string \| string[]` | 否 | 区域筛选，支持多选 |
| `road_names` | `string \| string[]` | 否 | 道路名称筛选，支持多选 |
| `disease_types` | `string \| string[]` | 否 | 病害类型筛选，支持多选 |

示例：

```json
{
  "years": ["2022", "2024"],
  "regions": ["上城区"],
  "road_names": ["秋涛北路", "凤起东路"],
  "disease_types": "严重疏松,脱空"
}
```

### 查询规则

- 除病害编号类精确查询外，这个接口的四个条件都按模糊匹配处理。
- 数组和逗号分隔字符串都会被拆成多选条件。
- 同一字段内多值之间是 `OR`。
- 不同字段之间是 `AND`。

### 返回结构

## 2. `/query/selectgroup`

### 用途

先根据 `year + number` 精确定位一个源病害，再读取该病害的 `对应病害群组编号`，最后用这个群组编号查询同组的其他病害。

### 请求信息

| 项目 | 内容 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/query/selectgroup` |

### 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `year` | `string` | 是 | 源病害所属年份 |
| `number` | `string` | 是 | 病害编号 |

示例：

```json
{
  "year": "2022",
  "number": "02_ZASZ_QTBL_01"
}
```

### 查询规则

1. 使用 `year + number` 在 `检测病害信息汇总表` 中定位源病害。
2. 从源病害中取出 `对应病害群组编号`。
3. 仅用 `对应病害群组编号` 查询同组其他病害，不再附带年份条件。
4. 返回结果中会排除源病害自身。

## 3. `/query/solve`

### 用途

根据 `year + number` 查询病害是否存在，并返回该病害在：

- `复测病害信息汇总表`
- `病害整改信息汇总表`

中的相关记录。

### 请求信息

| 项目 | 内容 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/query/solve` |

### 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `year` | `string` | 是 | 病害所属年份 |
| `number` | `string` | 是 | 病害编号 |

示例：

```json
{
  "year": "2024",
  "number": "02_ZASZ_FQDL_01"
}
```

### 查询规则

1. 先用 `检测病害信息汇总表.年份 + 编号` 校验病害是否存在。
2. 再用 `复测病害信息汇总表.年份 + 编号` 查询复测记录。
3. 再用 `病害整改信息汇总表.年份 + 编号` 查询整改记录。
4. 只要整改表命中至少一条记录，就认为该病害需要整改。
